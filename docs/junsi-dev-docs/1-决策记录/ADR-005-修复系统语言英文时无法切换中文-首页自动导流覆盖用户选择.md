# ADR-005：修复系统语言为英文时无法切换到中文：首页自动语言导流覆盖用户显式选择

| 属性 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-10-04 |
| 决策者 | AI Agent |

## 背景

用户报告：系统语言设为英文时，官网无法切换成中文。复现证据（Playwright 实测）：模拟 navigator.language = en-US，进入 /en/ 后点击顶栏「中」，最终 URL 仍是 /en/、html lang 仍为 en——完全无法停留在中文站。根因：Base.astro 的 <head> 内置自动语言导流脚本 `location.pathname === '/' && navigator.language.startsWith('en') && location.replace('/en/')`；而 Header.astro 计算的语言切换链接在英文页上恰好就是 `/`（`Astro.url.pathname.replace(/^\/en/, '') || '/'`），于是「点中 → 进入 / → 被立即弹回 /en/」形成死循环。影响范围经隔离 context 测试精确定界：仅 /en/（英文首页）受影响，/en/download/、/en/versions/ 等英文内页切换正常（脚本条件限定 pathname === '/'）。该脚本在重构前提交 e551120 中即存在，属既有 bug；Gate 0 已 fetch 远端确认无相关修复，故自研补丁。

## 决策

采用「记录用户语言选择」方案：① Header.tsx 的语言切换锚点新增 `data-lang-switch={targetLang}`（zh|en）；② Header.astro 通过事件委托在点击时写入 `localStorage['qml-lang']`，用 try/catch 包裹（隐私模式等存储不可用场景退化为「本次点击不生效」而非抛错）；③ Base.astro 的导流脚本改为优先读该键——`chosen === 'zh'` 时一律不自动跳转；`chosen === 'en'` 时仅在 pathname 为 '/' 时导流（关键约束：不可无条件 `location.replace('/en/')`，否则会把 /en/download/ 等英文内页也踢回 /en/ 首页——此缺陷在实现过程中一度引入并已自查修正）；未表达过偏好时完全沿用原有行为（仅首页按系统语言导流），从而保留英文用户首访自动进入英文站的既有体验。用户选定该方案（备选：切换链接加 ?lang= 参数绕过；直接删除自动重定向）。

## 备选方案

### 方案 记录用户语言选择（已采纳）
- 优点：根治——用户显式选择拥有最高优先级，与 Apple/Microsoft 官网的“首访按系统语言导流、之后尊重用户选择”惯例一致；保留原有的首访导流体验；无需改动任何链接。
- 缺点：引入一个本地存储键（qml-lang），需处理存储不可用的异常路径；写错会引入新缺陷（无条件导流会把英文内页也踢回 /en/）。
- 为何不选：尊重用户显式选择是正确行为；同时保住英文用户首访自动进入英文站的既有体验。

### 方案 切换链接加 ?lang= 参数绕过导流
- 优点：不写本地存储，无状态。
- 缺点：URL 多出参数，被分享/收藏后语义混乱（他人打开会跟随该偏好）；每个语言切换入口都需维护参数拼接；不利于 SEO 与规范化 URL。
- 为何不选：以牺牲 URL 干净度换取状态，长期成本高于一个本地存储键。

### 方案 直接删除自动导流
- 优点：改动最小，无状态，彻底消除死循环。
- 缺点：英文用户失去首访自动进入英文站的体验，相当于取消了一个既有功能；与用户所选方案不符。
- 为何不选：改动超出修复必要范围，会回退现有的英文用户体验。

## 影响
- src/layouts/Base.astro：<head> 自动语言导流脚本改为读取 localStorage 决策（zh 不跳 / en 仅从 '/' 跳 / 未表达偏好沿用系统语言）
- src/components/Header.tsx：HeaderProps 新增 switchLang，语言切换锚点输出 data-lang-switch 属性
- src/components/Header.astro：传入 switchLang；新增点击委托写入 qml-lang（try/catch 容错）
- 全站影响面：Base.astro 为 35 页共同布局，但仅首页的自动导流行为改变；下载/版本/平台/路由等业务逻辑未触及
- 验证：反向验证成立（抽掉修复后点「中」被弹回 /en/，lang=en，Bug 重现；还原后落到 / 且 lang=zh-CN）；7 个隔离 context 场景全通过；反方向（中文页点 EN）对称验证通过；构建 35 页通过；零 astro-island / 零 client:* 未被破坏
